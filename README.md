# PetCare — фронтенд

Веб-приложение для владельцев домашних животных: карточки питомцев, карта здоровья, журнал питания, напоминания и уведомления.

Чистые HTML, CSS и JavaScript — сборка и `npm install` не нужны.

## Как запустить у себя

Бэкенд принимает запросы только со страниц, открытых по адресу **`localhost`** или **`127.0.0.1`** (любой порт). Поэтому сайт нужно открыть через локальный сервер, а не двойным кликом по `index.html`.

**Вариант 1 — VS Code + Live Server**

1. Установите расширение **Live Server**.
2. Откройте папку проекта, нажмите правой кнопкой на `index.html` → **Open with Live Server**.
3. Откроется `http://127.0.0.1:5501` (или другой порт) — можно входить.

**Вариант 2 — Python**

```bash
python -m http.server 5500
```

Откройте `http://localhost:5500`.

> Не открывайте сайт по IP компьютера в сети (`http://192.168.…`): бэкенд такие адреса не пускает.

## Куда ходят запросы

Адрес API выбирается автоматически (`script.js`, константа `API`):

| Где открыт сайт | Куда идут запросы |
|---|---|
| `localhost` / `127.0.0.1` | напрямую в бэкенд `http://139.100.200.207:8080` |
| сервер после деплоя | через nginx-прокси `/api` → бэкенд (см. `nginx.conf`) |

## Демо-режим без бэкенда

Добавьте к адресу `?demo=1`, например `http://127.0.0.1:5501/?demo=1`. Данные хранятся в браузере, код подтверждения — `123456`.

## Деплой

Пайплайн в `.gitlab-ci.yml`: `lint` → `build` → `deploy`. Деплой запускается в ветке `master` и требует CI-переменных `DEPLOY_HOST`, `DEPLOY_USER`, `DEPLOY_KEY` (тип File).
