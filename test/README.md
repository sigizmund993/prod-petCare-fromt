# Тесты фронтенда

48 сценарных тестов: вход и регистрация, питомцы, карта здоровья, питание, напоминания и календарь, уведомления, аккаунт и сессия.

Тесты открывают приложение в демо-режиме (`?demo=1`), поэтому бэкенд не нужен и настоящие данные не трогаются.

## Как запустить

1. Запустите проект через локальный сервер из корня репозитория — Live Server в VS Code или `python -m http.server 5500`.
2. Откройте `http://127.0.0.1:5500/test/` (порт — ваш).
3. Слева появится список тестов (✅ / ❌ с причиной), справа — приложение, на котором они выполняются. Кнопка «Перезапустить» гоняет их заново.

Открывать `test/index.html` двойным кликом нельзя: тестам нужен тот же адрес, что и у приложения.

## Как добавить тест

В `tests.js`:

```js
test('название', async () => {
  await page('food');                 // перейти на страницу
  click('[data-action="add-food"]');  // нажать кнопку
  set($('#food-form'), 'name', 'Корм'); // заполнить поле
  eq(store().props.length, 1, 'записей'); // проверить
});
```

Перед тестами без входа вызывайте `await load(false)`, со входом — `await load(true)`: они сбрасывают демо-данные.
